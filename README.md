# Behavioral Modeling of Phase-Locked Loop (PLL) using Deep Learning

A MATLAB-based capstone project that trains a deep feedforward neural network to predict PLL performance metrics directly from circuit parameters — replacing slow SPICE/behavioral simulations with a sub-millisecond surrogate model.

---

## Project Description

Phase-Locked Loops are fundamental building blocks in RF front-ends, clock synthesizers, and wireless transceivers. Accurately predicting their performance (lock time, phase noise, output frequency) typically requires iterative simulation, which is time-consuming during design space exploration.

This project builds a **Deep Learning Toolbox-based behavioral model** that:
- Learns from 6 000 Monte-Carlo simulation samples generated by an analytical PLL model
- Predicts three key PLL metrics with R² ≥ 0.98 on a held-out test set
- Runs inference in microseconds compared to seconds per simulation call
- Uses **Deep Learning Toolbox** for robust and optimized training/inference

### Inputs (9 features)

| Parameter | Symbol | Unit |
|-----------|--------|------|
| Reference frequency | `fref` | Hz |
| PFD dead-band compensation current | `Idb` | A |
| Charge-pump current | `Icp` | A |
| CP leakage current | `Ileak` | A |
| Loop-filter resistance | `R` | Ω |
| Loop-filter capacitance | `C` | F |
| VCO gain | `Kvco` | Hz/V |
| VCO phase noise @ 1 MHz | `PN_vco` | dBc/Hz |
| Divider ratio | `N` | — |

### Outputs (3 targets)

| Metric | Symbol | Unit |
|--------|--------|------|
| Lock time | `LockTime_s` | s |
| Output phase noise @ 1 MHz offset | `PhaseNoise_dBcHz` | dBc/Hz |
| Output frequency | `Fout_Hz` | Hz |

## How to Run

Simply run the main script — it handles everything end-to-end:

```matlab
main
```

The script will automatically:

| Step | Description |
|------|-------------|
| 1 | Generate 6 000 PLL simulation samples (or load if already saved) |
| 2 | Train a 9→128→256→128→64→3 deep neural network using Adam |
| 3 | Evaluate model accuracy (R², RMSE, MAE, MAPE) on a held-out test set |
| 4 | Predict metrics for three example PLL designs (2.4 GHz / 28 GHz / 1 GHz) |
| 5 | Run sensitivity analysis and generate feature-importance bar chart |

All outputs are saved automatically:
- `data/pll_dataset.mat` — training dataset
- `models/pll_dl_model.mat` — trained network weights
- `results/figures/` — all plots as PNG files

> **Note:** First run generates data and trains the model (~500 epochs). Subsequent runs load the saved files instantly. To force re-training, set `FORCE_REGENERATE = true` in `main.m`.

## Neural Network Architecture

```
Input (9)  →  Dense(128, ReLU)  →  Dense(256, ReLU)  →  Dense(128, ReLU)  →  Dense(64, ReLU)  →  Output (3, Linear)
```

- **Optimizer:** Adam (lr = 3×10⁻⁴, β₁ = 0.9, β₂ = 0.999)
- **Regularisation:** L2 weight decay (λ = 10⁻⁴)
- **Early stopping:** patience = 30 epochs
- **Batch size:** 256
- **Data split:** 70% train / 15% validation / 15% test
